# Правила работы с JARVIS (Kirieshka v2)

Целевая ветка: strictly `osnova`. Не переключаться, не сливать другие ветки без прямого приказа.

## 1. Архитектурные табу
- **Zero-LLM Core:** Вся логика, автоматизация, протоколы и роутер команд работают на 100% оффлайн и детерминированно. Приложение полностью автономно без нейросетей.
- **Ограничение на LLM (Ollama):** Сейчас в коде уже реализована работа с LLM, но это исключительно архитектурный задел под будущие нововведения друга. Основной автор не собирается собирать и развивать программу под LLM: если локальная модель и используется, то только как опциональный изолированный режим «поболтать» (текстовый чат) без опоры на нейросети для базовой логики. Никаких платных облаков, тяжелых сеток (>8B), генерации картинок и векторных баз.
- **Интерфейс:** Только Tauri v2 + React (`ui/`). Связь с бэкендом через `EventBus` -> `gateway_service.py` (REST/WebSocket). PySide6 архивирован в `ui_archive/`, не трогать.
- **Безопасность:** Файлы — строго через `security/sandbox.py`. Никакого произвольного выполнения команд в cmd/PowerShell в обход Sandbox/PermissionManager.
- **Никакого хардкода путей:** Приложения и исполняемые файлы ищутся динамически (AppIndexer, реестр, системные переменные).
- **Логи:** Структуру `core/logging_config.py` и файл `errors.log` не трогать без конкретной аварии.

## 2. Кладбище отброшенных фич (НЕ ПРЕДЛАГАТЬ И НЕ ПИСАТЬ)
- Поканальный микшер звука под каждое приложение (только системная мастер-громкость).
- Бэкап сохранений игр.
- Автовосстановление VPN / сложные сетевые сторожи.
- Фоновые алерты и мониторинг перегрева железа.

## 3. Стандарты кода и автоматизации
- **Протоколы:** Никаких слепых `time.sleep()` для синхронизации с окнами. Только проверка хэндлов через WinAPI, ожидание процессов и отчет пользователю через голос (Piper) / EventBus.
- **Хирургические правки:** Трогать только строки, относящиеся к задаче. Без попутного рефакторинга и форматирования чужого кода.
- **Окружение и тесты:** Запуск тестов строго через `.venv\Scripts\pytest tests/`. Прогон обязателен после правок кода, для markdown/доков тесты не нужны.
