# Jarvis — справочник команд

**Статус:** актуальный рабочий справочник пользовательских команд.  
**Дата обновления:** 2026-10-23  
**Ветка:** `experimental` / `osnova`

Этот документ описывает **все пользовательские действия Jarvis** и фактический уровень их обработки в системе:

- **Router** — команда выполняется детерминированно и мгновенно, без обращения к LLM.
- **LLM + Tools** — запрос передаётся локальной языковой модели (Ollama), которая выбирает разрешённые инструменты (`Tool Calling`) в цикле до 5 раундов.
- **Router + LLM** — Router определяет намерение или запускает вспомогательный инструмент, а LLM формирует развернутый ответ или уточнение.
- **План** — возможность предусмотрена архитектурными планами, но пока не реализована.

## 1. Управление приложениями и процессами

### Открытие и запуск
**Действие:** запускает приложение, игру, исполняемый файл, ярлык Windows (`.lnk`, `.url`) или папку из `Workspace`.  
**Тип:** Router.  
**Примеры:**
```text
открой Steam
запусти Discord
включи Minecraft
вруби Telegram
стартуй Chrome
```
**Ключевые слова:** открой, запусти, включи, стартуй, запускай, вруби.

### Закрытие приложений
**Действие:** безопасно завершает процесс приложения через `tools/application_closer.py` с обязательным запросом подтверждения у пользователя.  
**Тип:** Router (с подтверждением).  
**Примеры:**
```text
закрой Steam
выключи Discord
заверши Telegram
останови Minecraft
выруби Spotify
```
**Ключевые слова:** закрой, останови, выключи, заверши, выруби.

### Проверка состояния процессов
**Действие:** проверяет, запущен ли процесс указанного приложения.  
**Тип:** Router.  
**Примеры:**
```text
проверь Steam
проверь Discord
запущен ли Telegram
работает ли Minecraft
```

### Сворачивание приложений
**Действие:** сворачивает активное окно указанного приложения.  
**Тип:** Router.  
**Примеры:**
```text
сверни Telegram
сверни Discord
```

## 2. Работа с файлами и папками (Workspace)

Все файловые операции изолированы песочницей `security/sandbox.py` строго внутри каталога `workspace/`.

### Поиск файлов и папок
**Действие:** ищет объект в каталоге Workspace с нормализацией имён и нечётким поиском по живому `WorkspaceIndex`.  
**Тип:** Router.  
**Примеры:**
```text
найди test.txt
где лежит config.json
покажи, где находится notes.md
```

### Чтение файлов
**Действие:** читает текстовое содержимое файла в Workspace.  
**Тип:** Router.  
**Примеры:**
```text
прочитай test.txt
открой файл readme.md
покажи содержимое config.json
выведи текст todo.txt
```

### Создание файлов
**Действие:** создаёт новый пустой файл или файл с указанным содержимым в Workspace.  
**Тип:** Router / LLM + Tools.  
**Примеры:**
```text
создай файл test.txt
создать новый файл notes.md
создай файл report.txt с содержимым Привет мир
```

### Создание папок
**Действие:** создаёт новую директорию внутри Workspace.  
**Тип:** Router.  
**Примеры:**
```text
создай папку Documents
создать новую папку Projects
```

### Запись и перезапись файлов
**Действие:** записывает или перезаписывает содержимое файла в Workspace. Операции перезаписи требуют подтверждения пользователя.  
**Тип:** Router / LLM + Tools.  
**Примеры:**
```text
запиши в файл todo.txt: купить хлеб
запиши в файл config.json на {"theme": "dark"}
перезапиши файл notes.txt на новый текст
```

### Переименование файлов
**Действие:** переименовывает файл в Workspace с запросом подтверждения.  
**Тип:** Router.  
**Примеры:**
```text
переименуй файл old.txt в new.txt
переименовать файл data.json на backup.json
```

### Копирование файлов
**Действие:** копирует файл в целевую папку или под новым именем с защитой от случайной перезаписи (`overwrite=False`). Требует подтверждения.  
**Тип:** Router.  
**Примеры:**
```text
скопируй файл data.txt в backup
скопировать файл photo.png в папку Images
```

### Перемещение файлов
**Действие:** перемещает файл в другую папку Workspace с подтверждением.  
**Тип:** Router.  
**Примеры:**
```text
перемести файл doc.pdf в Archive
переместить файл sound.wav в папку Audio
```

### Удаление файлов и папок
**Действие:** удаляет объект из Workspace. Обязательно требует подтверждения пользователя с отображением пути и типа объекта.  
**Тип:** Router.  
**Примеры:**
```text
удали файл old_notes.txt
стереть test.log
удали папку Temp
```

### Информация о файле
**Действие:** возвращает сведения о размере, дате изменения и типе объекта Workspace.  
**Тип:** Router.  
**Примеры:**
```text
информация о файле project.zip
свойства файла photo.png
сведения о notes.md
```

### Поиск по содержимому файлов
**Действие:** ищет вхождение строки или шаблона внутри файлов Workspace.  
**Тип:** LLM + Tools.  
**Примеры:**
```text
найди в файлах строку ERROR_CODE_42
в каком файле написано Hello World
```

## 3. Управление звуком и мультимедиа

Реализовано в `tools/media_control.py` через Windows CoreAudio API (с fallback на `pycaw`) и эмуляцию мультимедийных клавиш.

### Регулировка громкости
**Действие:** увеличивает или уменьшает общую системную громкость Windows, поддерживает указание точного шага в процентах.  
**Тип:** Router.  
**Примеры:**
```text
сделай громче
погромче
прибавь звук на 10
сделай громче 20
сделай тише
потише
убавь громкость на 15
убавь звук
```

### Выключение и включение звука (Mute / Unmute)
**Действие:** полностью отключает или восстанавливает системный звук Windows, раздельно отслеживая состояние заглушения.  
**Тип:** Router.  
**Примеры:**
```text
выключи звук
заглуши звук
без звука
мут
выруби звук
включи звук
разглуши звук
верни звук
размут
переключи звук
```

### Управление воспроизведением (Медиаплеер)
**Действие:** посылает системные мультимедийные сигналы активному медиаплееру или браузеру (Spotify, Яндекс Музыка, YouTube, AIMP и др.).  
**Тип:** Router.  
**Примеры:**
```text
пауза
плей
останови музыку
возобнови трек
следующий трек
пропусти трек
скипни песню
предыдущий трек
верни трек
```

## 4. Системная телеметрия и мониторинг ресурсов ПК

Реализовано в `tools/system_info.py` динамически, без зашивания конкретных моделей процессоров и видеокарт.

**Действие:** опрашивает загрузку CPU, распределение оперативной памяти RAM, свободное место на логических дисках, состояние и видеопамять GPU (через NVIDIA NVML, AMD, WMI, DXGI) и время непрерывной работы ПК (uptime).  
**Тип:** Router.  
**Примеры:**
```text
телеметрия
телеметрия пк
нагрузка пк
нагрузка процессора
состояние пк
состояние системы
статус пк
ресурсы пк
системные ресурсы
сколько памяти
сколько оперативы
че по нагрузке
покажи нагрузку
параметры пк
инфо о системе
```

## 5. Управление окном Jarvis

Реализовано напрямую в `services/command_router.py` через события `EventBus` (`ui.minimize`, `ui.maximize`, `ui.restore`, `ui.shutdown`).

**Действие:** сворачивает, разворачивает на весь экран, восстанавливает стандартный размер или безопасно завершает работу ассистента.  
**Тип:** Router.  
**Примеры:**
```text
свернись
сверни окно
свернись в трей
сверни jarvis
развернись
разверни окно
на весь экран
восстанови окно
верни обычный размер
закрой себя
закрой джарвис
закрой jarvis
выключись
закройся
заверши работу
```

## 6. Управление Ollama и моделями

Управляет локальным сервисом Ollama и памятью видеокарты/ОЗУ.

### Проверка статуса сервера
**Действие:** опрашивает доступность Ollama Server и список загруженных в память моделей.  
**Тип:** Router.  
**Примеры:**
```text
статус ollama
состояние ollama
```

### Запуск сервера Ollama
**Действие:** запускает локальный фоновый процесс сервера Ollama.  
**Тип:** Router.  
**Примеры:**
```text
запусти ollama
запустить ollama
запусти сервер ollama
```

### Остановка сервера Ollama
**Действие:** корректно останавливает только тот процесс Ollama, который был запущен Jarvis (не затрагивая системный фоновый сервис).  
**Тип:** Router.  
**Примеры:**
```text
останови ollama
остановить сервер ollama
```

### Выгрузка модели из памяти
**Действие:** немедленно освобождает VRAM и ОЗУ, выгружая активную языковую модель из памяти Ollama.  
**Тип:** Router.  
**Примеры:**
```text
выгрузи модель
выгрузить текущую модель
освободи модель
освободи память от модели
```

## 7. Веб-ссылки и браузер

**Действие:** открывает переданный HTTP или HTTPS URL в браузере по умолчанию.  
**Тип:** Router.  
**Примеры:**
```text
открой https://github.com
открыть http://localhost:11434
```

## 8. Составные и сложные запросы (LLM + Tool Calling)

Если запрос состоит из нескольких действий, содержит условие или сформулирован в свободной диалоговой форме, Command Router передаёт его в Ollama. Модель вызывает инструменты последовательно (до 5 раундов):

**Примеры:**
```text
найди config.json, прочитай его и создай рядом копию с именем config_backup.json
найди все txt-файлы в Workspace и скажи, о чем они
создай файл report.txt, запиши в него приветствие и открой его
```
