# Спецификация, статус реализации и Roadmap

**Проект:** JARVIS (Kirieshka v2)  
**Репозиторий:** `jelr1k/mama_kirilla_`  
**Ветки:** `osnova` (активная рабочая ветка), `integration/tauri-v2` (завершенная интеграционная ветка), `experimental` (миграция Tauri v2 / React), `satichik-dev` (Steam, протоколы, сайты)  
**Стек:** Python 3.11+ (Core, FastAPI/WebSocket шлюз :8765), Tauri v2 (Rust shell), React 19, Vite 7, Ollama, faster-whisper, Vosk, Piper TTS  

---

## 1. Готово и протестировано

- [x] **Архитектурный фундамент:**
  - Динамическое определение путей приложения (`core/app_paths.py`), отвязка от конкретного диска.
  - Пользовательские конфигурации и профили в `%APPDATA%\Jarvis`.
  - Слабосвязанная шина событий `EventBus` и 13 контроллеров слоя Presentation (плюс tray_icon.py).
  - Журналирование сессий в `logs/` с автоочисткой при перезапуске.

- [x] **Command Router и инструменты:**
  - Детерминированный роутинг однозначных команд мимо LLM.
  - Асинхронное исполнение тяжелых системных и сетевых команд без блокировки интерфейса.
  - Ограничение Tool Calling до 5 раундов.
  - Механизм подтверждения (`requires_confirmation`) для деструктивных действий (удаление файлов, закрытие приложений).

- [x] **Системные инструменты и телеметрия:**
  - Управление звуком и громкостью через Windows CoreAudio API (`pycaw`), раздельный трекинг Mute/Unmute.
  - Мультимедиа-команды плеера (пауза, воспроизведение, переключение треков).
  - Динамическая телеметрия: CPU (по ядрам), RAM, диски, GPU (NVML/AMD/WMI/DXGI), Uptime.
  - Создание скриншотов в `workspace/screenshots/` (`take_screenshot`).
  - Блокировка рабочего стола Windows (`lock_pc`, с пропуском в pytest).
  - Точное время и дата на русском (`get_current_time_date`).
  - Открытие системных папок и Проводника (`open_system_folder`).
  - Очистка чата (`clear_chat`).

- [x] **Файловая система и Workspace:**
  - Песочница `security/sandbox.py` (строго каталог `workspace/`).
  - Живой индекс `WorkspaceIndex` и единый `TargetResolver`.
  - Автоматическая и русская генерация алиасов со стеммингом (`AliasManager`).
  - Нечёткий поиск (fuzzy matching: порог 0.78 в резолвере путей `tools/paths.py`; 0.72 в `alias_manager.py` и `workspace_index.py`) и интерактивное разрешение неоднозначности.
  - Добавление файлов через проводник и Drag-and-Drop во вкладке Workspace.

- [x] **Голос и звук:**
  - STT: `faster-whisper` (модель `small`, int8 CPU) с ленивой загрузкой и нормализацией команд.
  - Детекция локальных моделей Whisper по путям и в кэше HF.
  - Wake Word: фоновый детектор `vosk` с подавлением во время вывода речи.
  - **Windows WASAPI Shared Mode:** микрофон открывается в совместном режиме (`exclusive=False`) без монопольной блокировки, благодаря чему Discord, Telegram и игры могут свободно использовать микрофон параллельно.
  - TTS: локальный синтез Piper TTS с отдельной очередью, кэшем и поддержкой заготовленных WAV-ассетов.
  - Безопасное скачивание моделей из UI без ошибок `'NoneType' object has no attribute 'write'`.

- [x] **Сетевой шлюз и API (Gateway):**
  - Асинхронный сервер FastAPI (`services/gateway_service.py`) на `127.0.0.1:8765`.
  - Полнодуплексный WebSocket (`/ws`): потоковая передача ответов LLM, транскрипция Vosk, статусы TTS, телеметрия ПК каждые 2.5 секунды.
  - REST эндпоинты для управления моделями, звуком, системными настройками, алиасами, сайтами, протоколами и обновлением.
  - Загрузочный экран `start/splash.py` (PySide6) с анимацией прогресса и проверкой готовности Gateway Healthcheck.

- [x] **Игры Steam и автоматизация протоколов:**
  - `SteamManager`: автоопределение путей установки Steam (`libraryfolders.vdf`, `appmanifest_*.acf`), парсинг списка установленных игр и запуск через `steam://rungameid/<appid>`.
  - `ProtocolsManager` и `StarkProtocols`: сценарии автоматизации ("Доброе утро" с погодой Open-Meteo, "Кино", "Защита", "Игра", "Работа", "Очистить стол").
  - Система профилей пользователей (Тони Старк, Гость, пользовательские профили).
  - `WebsiteManager`: база сайтов с автогенерацией алиасов и транслитерацией латиницы в кириллицу.

- [x] **Графический интерфейс Kirieshka v2 (Tauri v2 + React):**
  - Безрамочное окно Tauri v2 (`1120x760`), переключение в компактный HUD-виджет (`390x620`).
  - 9 разделов: Главная (Hero Orb, волна, тикер Vosk), Чат (стриминг, блок `<think>`, статус микрофона), Сеть, Протоколы, Команды, Алиасы (включая сайты), Ollama и инструменты, Воркспейс, Настройки.
  - Выдвижная панель истории и бенчмарков (`HistoryModal`).
  - Киберпанк тема на CSS Custom Properties с поддержкой `@property --c` для плавной интерполяции цвета ядра (idle/listen/think/speak).
  - Фоновый жизненный цикл и трей Windows (`presentation/tray_icon.py`): при закрытии окно сворачивается в трей, ядро остаётся активным; модальное окно `ConfirmModal.jsx` для подтверждения полного выключения.
  - Диагностика и автозагрузка: тестирование микрофона и Whisper без wake word (`/api/voice/test_recognition`), тестовый синтез TTS, автозапуск через реестр Windows (`/api/autostart`), опциональный предпрогрев моделей Ollama (`autoload_model`).
  - Старый PySide6 GUI сохранен в `ui_archive/` как аварийный fallback.

- [x] **Сеть, DPI-мониторинг и Удалённое управление (modules/):**
  - `NetworkChecker`: мониторинг доступности и задержки Discord Gateway, YouTube, Steam, Telegram API и GitHub с кэшированием результатов и поддержкой реверс-прокси/воркера без циклов редиректа.
  - `VPNManager`: поиск и запуск `service.bat` Запрета (winws), интеграция с Happ (`happ://connect`) и FlClashX с раздельным контролем окна и VPN-активности.
  - `TelegramBot`: управление ПК из Telegram (/status, /screen, /vpn, /ping, /lock, /sleep, /shutdown [мин], /shutdown_cancel, роутинг текстовых команд ассистента с возвратом ответа роутера в чат).

  - Отказоустойчивая доставка сообщений с автоматическим фоллбэком на plain text при ошибках парсинга HTML, неблокирующее исполнение системных команд через `asyncio.to_thread`, валидация отправителя `from.id`.
  - Поддержка Cloudflare Worker в качестве реверс-прокси для Telegram Bot API (`api_base_url`) в условиях блокировки IP-подсетей в РФ.
  - Валидация прав через белый список `allowed_chat_ids` в настройках.

- [x] **Каталог установленного софта и App Indexer:**
  - `AppIndexer` (`core/app_indexer.py`): автоматическое сканирование меню «Пуск» (APPDATA/PROGRAMDATA) и системного реестра Windows (`App Paths`).
  - Фильтрация служебных утилит, деинсталляторов и документации; безопасный резолв `.lnk` в реальные бинарники `.exe`.

  - Мгновенный запуск софта через `CommandRouter` без ожидания LLM с учётом прав `launch_application` и статуса запущенных процессов.

## 3. Дорожная карта (Roadmap)

### Потоковый синтез речи (Streaming TTS)
* Генерация и воспроизведение первых предложений ответа модели до окончания полного вывода текста LLM.

### Интеллектуальный Model Router
* Автоматический выбор локальной модели под конкретную задачу (легкая модель 1.5B-3B для простых ответов, более мощная 7B-14B для сложной логики и кода с учетом доступной VRAM).

### Каталог установленного софта (Workspace 2.0 / App Indexer) [РЕАЛИЗОВАНО]
* Управляемый реестр установленных программ Windows с возможностью запуска из UI, автогенерацией русских голосовых алиасов и интеграцией в Whisper.

### Автономная переносимая сборка (.exe)
* Сборка дистрибутива JARVIS в виде единого переносимого пакета:
  * Включение необходимого runtime.
  * Автоматическая валидация зависимостей без ручного запуска терминала.
  * Проверка переноса приложения между разными дисками и каталогами.

### Расширенный доступ к ПК и долгосрочная память
* Контролируемый выход за пределы `workspace/` через гранулярную систему разрешений пользователя.
* Долгосрочная память (персистентный векторный профиль пользователя между сессиями).

## 4. Известные особенности окружения

* **Локальный прокси (порт 10808):** При наличии сторонних утилит (Happ/V2Ray), выставляющих системный SOCKS4 прокси, Hugging Face/Whisper может выдавать `Unknown scheme for proxy URL`. Решение: запуск с изоляцией сетевых переменных окружения для локальных загрузок.
* **Потребление VRAM:** На системах с 4 ГБ видеопамяти рекомендуется использовать квантованные модели (Q4_K_M) до 7-8B параметров и выгружать модель из памяти при простое.
