# Установка и запуск dev-билда JARVIS (Kirieshka v2)

Руководство по развёртыванию ассистента из исходников на Windows 10/11 для разработчиков.

Стек проекта:
* **Бэкенд:** Python 3.12 (FastAPI шлюз на `127.0.0.1:8765`, WebSocket, Vosk / faster-whisper STT, Piper TTS, Ollama LLM, EventBus).
* **Фронтенд:** Tauri v2 + React / Vite (`ui/`), трей, нативные системные горячие клавиши, защищённый межпроцессный обмен токенами сессий.

---

## 1. Системные требования и зависимости

Для сборки и запуска dev-билда на машине разработчика требуются 5 компонентов:

| Компонент | Зачем нужен | Как быстро проверить в терминале |
|---|---|---|
| **Python 3.11 или 3.12 (64-bit)** | Ядро ассистента, нейромодули, локальный шлюз | `python --version` (должен быть 3.11.x или 3.12.x) |
| **Node.js LTS (v20+ или v22+) & npm** | Сборка React/Vite интерфейса и запуск Tauri CLI | `node -v` и `npm -v` |
| **Rust & Cargo (stable-msvc)** | Компиляция нативного окна Tauri v2 и системного трея | `rustc --version` и `cargo --version` |
| **MSVC C++ Build Tools** | Компилятор и линкер `link.exe` для Rust и Python-библиотек | Наличие `cl.exe` или рабочей нагрузки в VS Installer |
| **Ollama for Windows** | Локальная большая языковая модель для чата и команд | `ollama --version` |

> Подробнейшие ссылки на загрузку установщиков, скриншоты параметров VS Installer и команды автоматической установки через `winget` вынесены в отдельный документ: [`docs/PREREQUISITES_SETUP.md`](PREREQUISITES_SETUP.md).

## 2. Быстрый запуск в один клик (`start.bat`)

В корне проекта находится сценарий [`start.bat`](../start.bat), который автоматически подготавливает окружение и запускает приложение:

```cmd
start.bat
```

### Что делает `start.bat` автоматически:
1. Проверяет наличие Python 3.11/3.12 в `PATH`.
2. Проверяет существование каталога `.venv`. Если его нет — создаёт виртуальное окружение: `python -m venv .venv`.
3. Сравнивает зависимости и при необходимости обновляет пакеты из `config/requirements.txt` без лишней переустановки.
4. Проверяет порт `8765` и очищает зависшие процессы от прошлых сессий.
5. Запускает бэкенд в фоне (`pythonw.exe start/main.py --headless`).
6. Запускает сплэш-экран ожидания старта ядра (`python.exe start/splash.py`), опрашивающий `http://127.0.0.1:8765/health`.
7. После успешного ответа ядра шлюза поднимает dev-интерфейс Tauri v2 (`cd ui && npx tauri dev`).

## 3. Ручной запуск и отладка (для разработки)

Если нужно видеть логи бэкенда в живом времени или запускать фронтенд с горячей перезагрузкой (HMR):

### Шаг 1. Клонирование репозитория
```cmd
git clone https://github.com/jelr1k/mama_kirilla_.git
cd mama_kirilla_
git checkout osnova
```

### Шаг 2. Настройка виртуального окружения Python
```cmd
py -3.12 -m venv .venv
call .venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r config/requirements.txt
```
*(Для запуска автотестов также установите dev-зависимости: `pip install -r config/requirements-dev.txt`)*

### Шаг 3. Установка зависимостей фронтенда
```cmd
cd ui
npm install
cd ..
```

### Шаг 4. Запуск бэкенда в первом терминале
```cmd
call .venv\Scripts\activate
python start\main.py --headless
```
В консоли появится лог запуска шлюза FastAPI на `127.0.0.1:8765` и генерации сессионного токена.

### Шаг 5. Запуск интерфейса во втором терминале
```cmd
cd ui
npx tauri dev
```
Tauri скомпилирует Rust-оболочку (`src-tauri`), запустит Vite dev-сервер и откроет графическое окно приложения с активным треем в Windows.

## 4. Проверка корректности работы

После старта приложения можно выполнить быструю проверку:

1. **Проверка эндпоинта состояния шлюза:**
   ```powershell
   curl http://127.0.0.1:8765/health
   # Ожидаемый ответ: {"status":"ok","timestamp":...,"service":"jarvis-gateway"}
   ```

2. **Проверка сессионного токена:**
   Файл `%LOCALAPPDATA%\Jarvis\session.token` должен быть создан и содержать 64-символьную hex-строку.

3. **Проверка окна и трея:**
   В трее Windows (рядом с часами) должна появиться иконка Kirieshka v2. Клик по крестику окна сворачивает приложение в трей; пункт «Показать Jarvis» или клик по иконке разворачивает окно.

4. **Прогон набора автотестов:**
   ```cmd
   call .venv\Scripts\activate
   pytest -q
   ```
   Все тесты (670+) должны завершаться со статусом `passed`.

## 5. Настройка компонентов

### 5.1. Локальная нейросеть (Ollama)
1. Установите [Ollama for Windows](https://ollama.com/download/windows).
2. Загрузите рекомендуемую модель:
   ```cmd
   ollama pull qwen2.5:7b-instruct-q4_K_M
   # или легковесную:
   ollama pull qwen2.5:3b
   ```
3. Модель определяется автоматически либо задаётся в настройках интерфейса.

### 5.2. Голосовой ввод и синтез речи
* **Распознавание речи (STT):** Vosk и faster-whisper работают локально.
* **Синтез речи (Piper TTS):** Голоса ONNX кэшируются в `%LOCALAPPDATA%\Jarvis\models` и могут загружаться прямо из настроек.

## 6. Частые проблемы и их решение

* **Ошибка `command not found: tauri` при запуске:**
  Убедитесь, что выполнили `npm install` внутри каталога `ui/`, либо запускайте через `npx tauri dev`.
* **Ошибка линковщика Rust (`link.exe not found`):**
  Не установлены C++ Build Tools. Откройте Visual Studio Installer и установите нагрузку «Разработка классических приложений на C++».
* **Порт 8765 занят:**
  При аварийном завершении процесс `pythonw.exe` мог остаться в памяти. Закройте его через Диспетчер задач (`taskkill /F /IM pythonw.exe`) или перезапустите через `start.bat`, который очищает порты автоматически.
* **Не загружаются модули Python (`ModuleNotFoundError`):**
  Убедитесь, что активировано именно созданное окружение `.venv` (`call .venv\Scripts\activate`), а не глобальный системный Python.
