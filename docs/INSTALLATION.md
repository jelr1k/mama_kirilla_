# Установка и запуск JARVIS

Инструкция по развёртыванию ассистента из исходников и настройке зависимостей.

---

## 1. Системные требования

* **ОС:** Windows 11 (64-bit).
* **Интерпретатор:** Python 3.11 или 3.12 (рекомендуется 3.12).
* **Среда сборки UI:** Node.js 18+ и Rust (для сборки Tauri v2).
* **Локальный LLM-бэкенд:** [Ollama for Windows](https://ollama.com/download/windows).
* **Рекомендуемое железо:**
  * Процессор: 6 ядер (например, AMD Ryzen 5 3600 или лучше).
  * Оперативная память: от 16 ГБ RAM.
  * Видеокарта: от 4 ГБ VRAM (NVIDIA/AMD) для комфортного запуска квантованных моделей 3B-7B.

---

## 2. Развёртывание окружения

Из корня репозитория в терминале Windows (CMD / PowerShell):

```bat
:: 1. Создание виртуального окружения
py -3.12 -m venv .venv

:: 2. Активация окружения
.venv\Scripts\activate

:: 3. Обновление pip и установка библиотек
python -m pip install --upgrade pip
python -m pip install -r config\requirements.txt
```

---

## 3. Настройка компонентов

### 3.1. Ollama и модель
1. Установите и запустите сервер Ollama.
2. Скачайте рекомендуемую легковесную модель для чата и вызова тулов (например, Qwen 2.5):
   ```bash
   ollama pull qwen2.5:7b-instruct-q4_K_M
   # или ультралегкую:
   ollama pull qwen2.5:3b
   ```
3. Имя модели можно указать в настройках интерфейса JARVIS или в `config/settings.json`.

### 3.2. Голосовой ввод (STT) и синтез (TTS)
* **Whisper:** при первом голосовом запросе библиотека `faster-whisper` автоматически скачает модель `small` в кэш пользователя.
* **Piper TTS:** русские голосовые модели скачиваются в один клик через вкладку «Настройки» в приложении и сохраняются в `%APPDATA%\Jarvis\tts\voices\`.

---

## 4. Запуск приложения

* **Рекомендуемый запуск (единый скрипт):**
  ```bat
  start.bat
  ```
  Скрипт проверяет порты 8765 и 5174, запускает Python-ядро в headless-режиме, показывает сплэш-экран ожидания готовности шлюза (`start/splash.py`) и открывает десктопное окно Tauri.
* **Раздельный запуск для разработки:**
  1. Терминал 1 (бэкенд):
     ```bat
     .venv\Scripts\activate
     python start\bootstrap.py --headless
     ```
  2. Терминал 2 (фронтенд):
     ```bat
     cd ui
     npm install
     npx tauri dev
     ```
  *Примечание:* при закрытии окна на крестик интерфейс закрывается, а бэкенд продолжает работать в фоне и доступен через системный трей Windows. Полное завершение выполняется через меню трея или кнопку «Завершить работу» в интерфейсе.

---

## 5. Запуск тестов

Для проверки работоспособности модулей перед коммитом:

```bat
python -m pytest -q
```
