# Установка и запуск JARVIS

Руководство по развертыванию ассистента из исходников и настройке зависимостей.

---

## 1. Системные требования

* **ОС:** Windows 10 или Windows 11 (64-bit).
* **Интерпретатор:** Python 3.11 или 3.12 (рекомендуется 3.12, обязательно 64-bit с галочкой "Add python.exe to PATH").
* **Локальный LLM-бэкенд:** [Ollama for Windows](https://ollama.com/download/windows).
* **Для классического интерфейса (PySide6):** больше ничего не нужно! Никаких компиляторов Rust, C++ Build Tools и Node.js.
* **Для нового интерфейса (Tauri v2 + React):** дополнительно требуются Node.js LTS (18+) и Rust (`rustup` + MSVC C++ Build Tools).

---

## 2. Быстрый запуск в один клик

В корне проекта подготовлены автоматические скрипты, которые сами создают виртуальное окружение `.venv`, ставят недостающие библиотеки из `requirements.txt` и запускают приложение:

### Вариант А. Классический стек (без Rust и Node.js)
Если у вас или вашего друга нет Rust, Cargo и Node.js, используйте классический запуск:
```bat
start_legacy.bat
```
*Что происходит:* скрипт сам создаст `.venv`, установит все Python-пакеты (PySide6, FastAPI, Whisper, Piper TTS и др.) и откроет полноценное десктопное окно ассистента на PySide6.

> **Подсказка:** основной скрипт `start.bat` также автоматически определяет отсутствие Node.js или Rust в системе и сам переключается на классический PySide6 UI вместо падения с ошибкой.

### Вариант Б. Новый стек (Tauri v2 + React)
Если установлены Node.js и Rust:
```bat
start.bat
```
*Что происходит:* скрипт запускает Python-бэкенд в фоне, показывает сплэш-экран и открывает современный UI на Tauri v2.

## 3. Ручная установка и запуск через консоль

Если вы предпочитаете настраивать окружение вручную через CMD или PowerShell:

### Шаг 1. Клонирование и переход в репозиторий
```bat
git clone https://github.com/jelr1k/mama_kirilla_.git
cd mama_kirilla_
git checkout osnova
```

### Шаг 2. Создание виртуального окружения Python
```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
```

### Шаг 3. Установка Python-зависимостей
```bat
python -m pip install --upgrade pip
pip install -r requirements.txt
```
*(Или `pip install -r config/requirements.txt` - они взаимозаменяемы).*

### Шаг 4. Запуск интерфейса

* **Классический PySide6 интерфейс (чистый Python, без сторонних компиляторов):**
  ```bat
  python start\main.py --legacy-gui
  ```
  *(или `python start\bootstrap.py --legacy-gui`)*

* **Фоновый бэкенд без GUI (только шлюз, Telegram-бот и голосовой ассистент):**
  ```bat
  python start\bootstrap.py --headless
  ```

* **Сборка и запуск Tauri v2 (требуются Node.js и Rust):**
  1. В первом терминале запустить бэкенд:
     ```bat
     .venv\Scripts\activate
     python start\bootstrap.py --headless
     ```
  2. Во втором терминале запустить фронтенд:
     ```bat
     cd ui
     npm install
     npx tauri dev
     ```

## 4. Настройка компонентов

### 4.1. Локальная языковая модель (Ollama)
1. Установите и запустите [Ollama](https://ollama.com/download/windows).
2. Скачайте модель для чата и вызова инструментов:
   ```bash
   # Рекомендуемая быстрая модель:
   ollama pull qwen2.5:7b-instruct-q4_K_M

   # Ультралегкая модель для слабых ПК:
   ollama pull qwen2.5:3b
   ```
3. Модель подхватывается автоматически или выбирается в настройках интерфейса во вкладке "Настройки" / "Ollama".

### 4.2. Голосовой ввод (STT) и озвучка (TTS)
* **Распознавание голоса (Whisper):** модель `small` загружается автоматически в кэш пользователя при первой активации микрофона или фразы вызова (wake word).
* **Синтез речи (Piper TTS):** русские голоса скачиваются в один клик прямо из вкладки "Настройки" в приложении и сохраняются в `%APPDATA%\Jarvis\tts\voices\`.

### 4.3. Удаленное управление через Telegram (опционально)
Если хотите управлять компьютером с телефона (статус ПК, скриншот экрана, блокировка, VPN, выключение):
1. Создайте бота через `@BotFather` и скопируйте токен.
2. В файле `config/settings.json` (или через интерфейс настроек) заполните блок `telegram`:
   ```json
   "telegram": {
     "enabled": true,
     "bot_token": "ВАШ_ТОКЕН_БОТА",
     "allowed_user_ids": [123456789]
   }
   ```
   Узнать свой ID можно через бота `@userinfobot`. Бот отвечает только пользователям из белого списка `allowed_user_ids`.

## 5. Проверка работоспособности (тесты)

Перед началом работы можно проверить, что все модули функционируют штатно:

```bat
.venv\Scripts\activate
python -m pytest -q
```
Должно пройти 660+ тестов без критических ошибок.

## 6. Решение возможных проблем

* **Ошибка "Python не найден" или 'py' не является внутренней командой:**
  Переустановите Python 3.12, обязательно отметив галочку **Add python.exe to PATH** на первом экране инсталлера.
* **Порты 8765 или 5174 уже заняты:**
  Скрипты `start.bat` и `start_legacy.bat` автоматически прибивают зависшие процессы с этих портов перед стартом. При ручном запуске закройте старые процессы `python.exe` через Диспетчер задач.
* **Ошибка компиляции wheel при pip install:**
  Убедитесь, что используется Python 3.11 или 3.12 (не 3.13+, так как под 3.13 еще не для всех нейросетевых библиотек собраны готовые бинарные колеса под Windows).
