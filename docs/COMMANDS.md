# Справочник команд JARVIS

Документ содержит полный список поддерживаемых голосовых и текстовых команд ассистента.

**Способы обработки:**
* **Router** - мгновенное прямое исполнение детерминированным модулем без обращения к LLM.
* **Router (с подтверждением)** - прямое действие с обязательным запросом подтверждения («да» / «нет»).
* **LLM + Tools** - обработка нейросетью Ollama через механизм Tool Calling (до 5 раундов).

## 10. Алиасы и нормализация имён

* **Автоматические алиасы:** при добавлении файла в Workspace автоматически регистрируются его имя, stem (без расширения) и стандартные транслиты (`Steam.url` -> `steam`).
* **Русские алиасы:** встроен словарь устойчивых соответствий (`Steam` -> `стим`, `Discord` -> `дискорд`, `Minecraft` -> `майнкрафт` и др.).
* **Fuzzy matching:** нечёткий поиск файлов с порогом сходства 0.78 в резолвере путей `tools/paths.py` (в индексаторе воркспейса и менеджере алиасов базовый порог 0.72). При неоднозначности ассистент выводит нумерованный список вариантов без угадывания.

## 11. Сеть: VPN и Запрет блокировок

Отдельная вкладка «Сеть» в интерфейсе и команды в чате. Пути не прописаны в коде: ассистент сам ищет `service.bat` от Запрета и клиенты Happ / FlClashX (запущенный процесс, реестр деинсталлятора, ярлыки «Пуск», типовые каталоги). Если ничего не найдено, возвращается сообщение «Не удалось определить местоположение нужных файлов».

| Действие | Примеры команд | Тип | Примечание |
|---|---|---|---|
| Открыть service.bat (Запрет) | `запрет`, `включи запрет`, `запусти запрет`, `открой service.bat` | Router (Async) | Открывает окно `service.bat`; сборку-архив распаковывает в `%APPDATA%/Jarvis/zapret` |
| Подключить VPN | `впн`, `включи впн`, `впн happ`, `впн flclashx` | Router (Async) | Happ получает `happ://connect`, FlClashX запускается с нажатием кнопки подключения через UI Automation; без имени клиента берётся найденный по приоритету Happ → FlClashX |
| Статус сети | `статус впн`, `состояние vpn`, `статус запрет`, `проверь zapret` | Router (Async) | Найденные пути клиентов и признак работы `winws.exe` |

## 12. Команды Telegram-бота (Удалённое управление ПК)

Команды отправляются напрямую в личный диалог с ботом в Telegram (доступ строго по белому списку `allowed_chat_ids`):

| Команда | Описание | Примечание |
|---|---|---|
| `/status` | Сводка состояния ПК (CPU, RAM, GPU, температура) и статус активности Запрета и VPN | Мгновенный мониторинг ПК |
| `/screen` | Снимок экрана рабочего стола в виде фотографии в чат | Контроль запущенных окон |
| `/vpn` | Статус активности Запрета (winws) и клиентов Happ / FlClashX | Справка по статусам |
| `/vpn zapret` | Запуск `service.bat` Запрета на компьютере | Удалённый запуск winws |
| `/vpn happ` | Запуск и подключение клиента Happ через `happ://connect` | Включение VPN |
| `/vpn flclash` | Запуск и подключение FlClashX | Включение Clash |
| `/ping` | Проверка пинга и доступности сервисов (Discord, YT, Steam, TG, GitHub) с ПК | Тестирование сети |
| `/lock` | Блокировка рабочего стола Windows | Блокировка сеанса пользователя |
| `/sleep` | Перевод компьютера в спящий режим | Энергосбережение |
| `/reboot [мин]` | Планирование перезагрузки ПК (по умолчанию 60 сек, `0` — немедленно) | Таймер перезагрузки |
| `/shutdown [мин]` | Планирование выключения ПК через указанное число минут (по умолчанию 1 мин) | Таймер отключения питания |
| `/shutdown_cancel` | Отмена ранее запланированного выключения или перезагрузки (`shutdown /a`) | Предотвращение выключения/перезагрузки |
| `/help` | Справочник поддерживаемых команд бота | Подсказка в чате |
| *Текстовый запрос* | Отправка любого обычного текста перенаправляет команду в `Command Router` JARVIS | Выполнение ассистентом |
