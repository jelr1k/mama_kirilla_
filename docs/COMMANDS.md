# Справочник команд JARVIS

Документ содержит полный список поддерживаемых голосовых и текстовых команд ассистента.

**Способы обработки:**
* **Router** — мгновенное прямое исполнение детерминированным модулем без обращения к LLM.
* **Router (с подтверждением)** — прямое действие с обязательным запросом подтверждения («да» / «нет»).
* **LLM + Tools** — обработка нейросетью Ollama через механизм Tool Calling (до 5 раундов).

---

## 1. Управление приложениями и окнами

| Действие | Примеры команд | Тип | Примечание |
|---|---|---|---|
| Запуск приложения / игры | `открой Steam`, `запусти Discord`, `вруби Telegram`, `включи Minecraft` | Router | Ищет в Workspace и системных путях |
| Безопасное закрытие | `закрой Steam`, `выключи Discord`, `заверши Telegram`, `останови игру` | Router (подтверждение) | Мягкое закрытие или завершение дерева процессов |
| Проверка статуса | `проверь Steam`, `запущен ли Discord`, `работает ли Minecraft` | Router | Возвращает статус процесса |
| Сворачивание окна | `сверни Telegram`, `сверни Discord`, `сверни окно` | Router | Сворачивает окно приложения |

| Действие | Примеры команд | Тип | Примечание |
|---|---|---|---|
| Поиск файла | `найди report.txt`, `где лежит notes.md` | Router | Поиск по `WorkspaceIndex` |
| Чтение файла | `прочитай todo.txt`, `покажи содержимое config.json` | Router | Выводит текст в чат |
| Создание файла | `создай файл test.txt`, `создай заметку с текстом Привет` | Router / LLM | Безопасное создание |
| Удаление файла | `удали файл dump.log` | Router (подтверждение) | Защита от случайного удаления |
| Список файлов | `покажи файлы в workspace`, `список файлов` | Router | Перечень объектов каталога |

## 8. Алиасы и нормализация имён

* **Автоматические алиасы:** при добавлении файла в Workspace автоматически регистрируются его имя, stem (без расширения) и стандартные транслиты (`Steam.url` → `steam`).
* **Русские алиасы:** встроен словарь устойчивых соответствий (`Steam` → `стим`, `Discord` → `дискорд`, `Minecraft` → `майнкрафт` и др.).
* **Fuzzy matching:** нечёткий поиск файлов с порогом сходства 0.72. При неоднозначности ассистент выводит нумерованный список вариантов без угадывания.
