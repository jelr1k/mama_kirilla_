# Архив документации

Здесь лежат документы, которые больше не являются актуальным руководством, но сохраняются как исторический контекст. Актуальная документация находится в [`docs/INDEX.md`](../INDEX.md).

## Что и куда переносится

| Каталог | Содержимое |
|---|---|
| [`reviews/`](reviews/) | Разовые аудиты кода, ревью и отчёты о найденных проблемах. Не обновляются после исправления проблем. |
| [`plans/`](plans/) | Завершённые или отменённые планы реализации и декомпозиции. |
| [`legacy_docs/`](legacy_docs/) | Спецификации, гайды и статусы ранних версий проекта. |

## Правила архивации

1. Переносить документ в архив, если он описывает уже выполненную работу, устаревшую архитектуру или разовое исследование.
2. Актуальные знания из архивного документа переносить в профильный актуальный документ (`ARCHITECTURE.md`, `COMMANDS.md`, `PROJECT_STATUS.md` и т.д.), а не оставлять только в архиве.
3. Не архивировать документы, на которые ссылаются `AGENTS.md`, `README.md` или актуальные руководства.
4. Ссылки на архивные файлы давать относительными путями; сами архивные документы не переписывать, кроме исправления совсем битых ссылок.
