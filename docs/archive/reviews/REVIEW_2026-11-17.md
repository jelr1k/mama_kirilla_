## P0. Безопасность

### 1. Бэкдор в авторизации Gateway
- `services/gateway/deps.py:17-23`: проверка токена пропускается, если выставлен `JARVIS_DISABLE_AUTH` или `PYTEST_CURRENT_TEST`, плюс fail-open, если токена нет вообще (`return ""`).
- Проверки `PYTEST_CURRENT_TEST` встречаются ещё в продовом коде (всего 7 мест, в т.ч. `core/application.py`, `services/gateway_service.py`, `tools/system_actions.py`).
- Авторизация реализована дважды: middleware в `services/gateway_service.py` и dependency в `services/gateway/deps.py`.
- **Риск:** любая переменная окружения выключает защиту; тесты роутеров авторизацию не проверяют вообще, зелёный прогон ничего не гарантирует.
- **Решение:** оставить одну реализацию (dependency), в тестах подменять её через `app.dependency_overrides[verify_session_token]`, из продового кода убрать env-проверки и fail-open. Добавить пару тестов, что без токена эндпоинт отдаёт 401.

## P1. Окружение и зависимости

### 2. `torch` и `transformers` в базовом `requirements.txt`
- `config/requirements.txt:23,26` тянет гигабайты ради опциональных TTS-движков (Silero и др.).
- **Решение:** вынести в `config/requirements-tts-extra.txt`, в движках делать ленивый импорт с понятной ошибкой, если пакета нет.

### 3. Разные версии Python локально и в CI
- Локально `.venv` на Python 3.14, в `tests.yml` и `updater-release.yml` прописан 3.12.
- **Решение:** выбрать одну целевую версию (или матрицу 3.12/3.14 в `tests.yml`).

### 4. Неработающая команда тестов в `AGENTS.md`
- `.venv\Scripts\pytest.exe` в venv отсутствует.
- **Решение:** заменить на `.venv\Scripts\python.exe -m pytest tests/`.

## P2. Нарушения правил `AGENTS.md`

### 5. Хардкод в `services/stark_protocols.py`
- Координаты Москвы для погоды в утреннем брифинге (строка 331): вынести в настройки.
- Зашитые списки процессов на закрытие (строки 258, 284) и `opera.exe` как единственный разрешённый браузер для кино; в `PROTECTED_PROCESS_NAMES` нет `vivaldi.exe`.
- Старый `execute_protocol` с ветками `if protocol_id == "morning" / "cinema" / "game" ...` (строки 498+) живёт параллельно с `execute_dynamic_protocol` на JSON-конфиге. Вызывается из `integrations.py`, `protocols_dispatcher.py`, `gateway_service.py`.
- **Решение:** перевести встроенные протоколы в дефолтный JSON-конфиг, оставить один путь исполнения, браузер определять через AppIndexer / браузер по умолчанию.

### 6. Легаси PySide6 в точке входа
- `start/main.py` содержит инициализацию PySide6 и контроллеры из `presentation/legacy/` (17 упоминаний), хотя UI архивирован в `ui_archive/`. На `presentation/legacy/` до сих пор гоняются тесты.
- **Решение:** выпилить PySide6-ветку из `start/main.py`, `presentation/legacy/` и его тесты перенести в архив.

## P3. Чистка

### 7. Остатки старого нейминга
- `ui/src/App.jsx` читает `localStorage` с фоллбэком на ключи `kirieshcka_*`, `ui/src-tauri/src/lib.rs:99` ищет токен в старой папке `Jarvis`.
- **Риск:** бэкенд пишет токен в одно место, фронт читает протухший из другого.
- **Решение:** один раз мигрировать старые ключи/папку при старте и удалить фоллбэки.

### 8. Глотание ошибок
- Около 62 мест с `except Exception: pass`.
- **Решение:** не трогать всё подряд, а пройтись по критичным модулям (VPN, окна, процессы, протоколы) и заменить `pass` на `logger.exception(...)`.
