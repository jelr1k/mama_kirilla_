# Концепт нового интерфейса (Motion Studio / Tactile Hardware)

Статус: **Экспериментальный прототип (Sandbox)**  
Переключение: `Настройки -> Общие параметры -> Режим интерфейса` (`assistant_ui_mode` в `localStorage`) или кнопка `КЛАССИКА` в верхнем баре.

## 1. Утверждённая идея и визуал
- **Стиль:** Tactile Hardware / Teenage Engineering — матовый графит, перфорированная сетка, винты и LED-индикаторы, 3D-клавиши с физическим проваливанием при нажатии, оранжевый (`#ff4d00`) и лаймовый (`#b8ff3b`) акценты.
- **Компоновка:** Живой центр (`OscilloscopeCanvas` в режимах `WAVE` и `MATRIX`, реагирующий на курсор, громкость и голос) + свободный рабочий стол с перетаскиваемыми, сворачиваемыми и разворачиваемыми на весь экран (`layoutId`-морфинг) аппаратными модулями (`HardwareModule`).
- **Тактильность:** Встроенный Web Audio API синтезатор коротких механических кликов (`sfx.js`, переключается через `SFX: ON/OFF`), поворотный энкодер (`RotaryKnob`) для громкости, аппаратные пэды протоколов с LED-секвенсором.

## 2. Текущие проблемы и пробелы (что нужно доработать)
1. **Понятность (UX / порог входа):**
   - Сейчас сходу неочевидно, что куда нажимать, что модули можно таскать за рельсу, а энкодер крутить мышкой/колесом.
   - Слишком много английского техножаргона (`ARM VOICE TRIGGER`, `EXEC`, `OSC: WAVE`), нужно перевести ключевые подписи на понятный живой русский и сделать визуальную иерархию очевиднее.
   - При изменении размера окна модули с жёсткими `defaultPos` могут наезжать друг на друга или на осциллограф — нужна адаптивная раскладка.

2. **Отсутствующий функционал (в новом UI пока нет половины возможностей классического интерфейса):**
   - **Настройки** — полностью отсутствуют внутри Motion Studio (общие параметры, голос/STT/Piper TTS, выбор микрофона, Ollama, Telegram-бот, безопасность, рофл-режим, обновления).
   - **Алиасы и каталоги** (`Aliases`, `AppsSubtab`, `WebsitesSubtab`).
   - **Сеть** (`Network`).
   - **Ollama и Тулы** (`Ollama`).
   - **Воркспейс** (`Workspace`).
   - **Полноценный каталог команд** (`Commands`) и **Журнал истории** (`HistoryModal`).
   - **Подключение к бэкенду:** сейчас интерфейс полностью изолирован в Sandbox (`mockData.js`), нет реального `useAssistant` / `apiFetch` / `EventBus`.
