# GEMINI.md — точка входа для Gemini

Этот файл оставлен как короткий указатель. Полный контекст и правила больше не дублируются здесь, чтобы документация не расходилась.

- [`../AGENTS.md`](../AGENTS.md) — обязательные правила работы в репозитории и архитектурные ограничения.
- [`AI_GUIDE.md`](AI_GUIDE.md) — стек, структура проекта, ключевые файлы и принципы правок.
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — архитектура подсистем, поток данных и жизненный цикл.
- [`INDEX.md`](INDEX.md) — навигация по всей актуальной документации.

**Кратко:** JARVIS (Kirieshka v2) — локальный ассистент под Windows 11. Python 3.12 + FastAPI/WebSocket шлюз, Tauri v2 + React/Vite, Ollama как опциональный модуль, faster-whisper STT, Vosk wake word, Piper TTS. Активная ветка — `osnova`. Базовые команды должны обрабатываться детерминированным Command Router без вызова LLM.
