# Статус реализации Jarvis

**Дата обновления:** 2026-10-22  
**Ветка:** `osnova`  
**Репозиторий:** `jelr1k/mama_kirilla_`

Документ отражает фактическое состояние кода ветки `osnova`, а не планируемое состояние.

## Реализовано

- [x] Автоматическое определение корня Jarvis и рабочего `Workspace` относительно расположения приложения.
- [x] Пользовательские настройки и алиасы в `%APPDATA%\\Jarvis`.
- [x] Sandbox и проверки путей перед файловыми операциями.
- [x] Файловые инструменты для поиска, чтения, создания и других поддерживаемых операций.
- [x] Безопасный запуск объектов из `Workspace` с поддержкой Windows-ярлыков.
- [x] Добавление файлов в `Workspace` через QFileDialog и drag-and-drop прямо во вкладке `Workspace`.
- [x] Автоматическая регистрация базовых алиасов для объектов `Workspace` без обращения к LLM.
- [x] Идемпотентная регистрация автоматических алиасов без дублирования и без перезаписи пользовательских алиасов.
- [x] Запуск любого существующего объекта `Workspace`, включая папки, через единый launch path.
- [x] Живой `WorkspaceIndex`, построенный по фактическому содержимому `Workspace`.
- [x] Единый resolver для разрешения объектов внутри `Workspace`.
- [x] Контролируемое fuzzy-сопоставление и обработка неоднозначных результатов.
- [x] Command Router для однозначных команд без обязательного обращения к LLM.
- [x] Прямое разрешение объектов `Workspace` через индекс для соответствующих команд Router.
- [x] Ограниченный набор tools для конкретного запроса.
- [x] Multi-round Tool Calling с ограничением в 5 раундов.
- [x] Ollama Server и управление моделью из UI раздельно.
- [x] Освобождение модели при закрытии Jarvis при сохранении работающего Ollama Server.
- [x] Расширенное логирование Command Router, ToolExecutor, LLM/Ollama и управления процессами.
- [x] Unit/regression-тесты ключевых компонентов и GitHub Actions для тестов.
- [x] Локальный голосовой ввод через `faster-whisper`.
- [x] Голосовой ввод использует существующий путь обработки сообщений: распознанный текст передаётся в ChatService/Command Router.
- [x] Нормализация голосовых команд в `voice.command_normalizer` (распознавание расширений файлов «точка txt», знаков препинания, слэшей).
- [x] Whisper загружается лениво при первом распознавании.
- [x] Текущая конфигурация Whisper: модель `small`, `cpu`, `int8`, язык `ru`, целевая частота дискретизации 16 kHz, `beam_size=5`, `vad_filter=True`.
- [x] Локальный TTS через Piper с отдельным worker-потоком и очередью воспроизведения.
- [x] Общий канал `speech.requested` для готовых ответов ChatService и шуточных реплик RoflService.
- [x] Выбор/скачивание русского голоса, тестовая фраза, скорость и громкость в настройках; автоматическая озвучка по умолчанию отключена.
- [x] Подавление wake-word распознавания во время синтеза и воспроизведения, чтобы избежать ложного срабатывания от динамиков.
- [x] Детектор wake word на Vosk: настраиваемая ключевая фраза и базовый цикл повторного ожидания после голосового ввода/ошибки.
- [x] Стабильное поведение скролла в чате во время потоковой генерации (сохранение позиции при прокрутке вверх).
- [x] Единое подтверждение `close_application` для Command Router и LLM Tool Calling с обязательным подтверждением (`requires_confirmation: True`).
- [x] Гарантированное пробуждение потока ожидания подтверждения при `shutdown()` и настраиваемый таймаут (60с) в `ChatService._confirm_tool()`.
- [x] Быстрая проверка зависимостей (`start/check_dependencies.py`) перед запуском без повторного `pip install`.
- [x] Безопасная проверка назначения и защита от случайной перезаписи при операциях копирования и перемещения файлов (`tools/files.py`).
- [x] Отслеживание управляемого процесса Ollama (`_managed_process`) во избежание остановки сторонних серверов.

- [ ] Автоматический Model Router для выбора модели по сложности задачи.
- [ ] Финальная сборка и проверка `.exe`.
- [ ] Полная проверка установки зависимостей и переносимости конечной сборки.

## Известные проблемы и особенности

### 1. Прокси в голосовом вводе

В окружении пользователя `faster-whisper`/Hugging Face иногда получает `socks4://127.0.0.1:10808` от локального прокси Happ и выдаёт `Unknown scheme for proxy URL`. Проблема относится к сетевому окружению, а не к модели Whisper. Рабочий обход был проверен через очистку proxy-переменных для текущей CMD-сессии.

### 2. Память и длина сессии

При длительной сессии переписки история диалога накапливается в памяти и передаётся в Ollama целиком. В планах — внедрение скользящего окна контекста.

## Важное уточнение

Наличие `WorkspaceIndex` не означает, что вся файловая подсистема уже полностью завершена. Индекс является текущим источником истины для существования объектов `Workspace` в подключённых к нему сценариях. Операции, связанные с процессами, например закрытие приложения, по-прежнему используют отдельную процессную логику.
